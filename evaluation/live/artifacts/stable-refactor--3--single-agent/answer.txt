**Approach:** Replace the O(n²) nested loop search with a single-pass dictionary lookup:
- **O(1) user lookup:** `if user in seen` replaces the inner loop
- **First-seen order:** Python 3.7+ guarantees dict insertion order; items are added in first-occurrence sequence
- **Same output:** Accumulates totals identically; `list(seen.values())` preserves insertion order
- **No input mutation:** Only reads from rows parameter
