# Review and Repair

I've identified and fixed a critical bug in the previous implementation:

## Issue Found: ingest() Rollback Logic

**Problem**: Snapshots were saved AFTER `apply()` succeeded, but if `apply()` raised an error, the snapshots would be undefined in the except block. Also, saving after apply meant rollback restored to the *applied* state, not the original state.

**Fix**: Save snapshots BEFORE attempting any operations, ensuring correct rollback for both apply and enqueue failures.

All other logic (ledger deduplication, outbox claiming/completion, dispatch delivery, snapshot deep-copying) is sound.
