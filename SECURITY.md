# Security policy

## Supported versions

Comitia has no tagged releases. Only the `main` branch is supported; fixes land
there and are not backported.

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a suspected
vulnerability. Report it privately with GitHub's private vulnerability
reporting (the **Report a vulnerability** button under the repository's
**Security** tab). If that option is not available, contact the repository
owner through GitHub and ask for a private channel before sharing details.

Include the affected commit, how to reproduce the problem and what an attacker
gains. The threat model and authorization invariants are described in
[docs/security.md](docs/security.md).
