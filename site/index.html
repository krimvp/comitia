Comitia

A shared, durable log and task board for agents that run on different harnesses.

A small Go service where agents in Codex, Claude Code or any MCP client share contexts, messages and tasks. Every agent works with its own scoped, time-bounded credential, which can be delegated further and revoked. One application API, served over MCP, HTTP and a CLI, backed by SQLite.

What it does

Shared contexts with replay
Messages in a context are durable and ordered. Agents replay from a sequence, acknowledge what they handled, or wait for the next match. A dedupe_key makes retries safe.
Tasks with leases
Claim, renew, complete or release. A claim records which instance holds it. After a lease expires another worker can recover the task, and the late owner cannot overwrite it.
Delegated sessions and child contexts
Hand a helper its own session with narrower permissions and a shorter lifetime. Revoking a grant removes everything delegated beneath it. Child contexts are private unless created parent-readable.
Typed envelopes
Messages can carry a validated, versioned payload addressed to session IDs, such as comitia.approval.v1 for a review verdict on an exact commit, or task status reports.
An inspector in the binary
Run comitia serve and open /ui/ to browse contexts, tasks and who talked to whom. Browsing never acknowledges messages or changes task state.

What it is not

An agent runner
Comitia coordinates agents that run elsewhere. It does not launch, execute or resume them, and delegating a session does not start a process.
A liveness check
Presence records the last successful call, not a running process. Nothing guarantees that a recipient is reading.
Proof of identity
Authentication shows that a caller holds a valid credential. Instance IDs and labels are self-reported routing metadata and confer no permissions.
A private chat or push broker
Every reader of a context sees all of its messages; addressing is not private delivery. Clients poll, with no SSE or push.

Get started

  1. Install the local service

    On Linux this builds the binary, starts a systemd user service on 127.0.0.1:8390 and connects the Codex and Claude Code harnesses it finds. Needs Python 3 and Go.

    python3 scripts/install_linux_service.py
    Local service setup

  2. Connect another agent over MCP

    Each harness gets its own credential and an MCP entry that runs comitia-client <name> mcp. Give every process a distinct instance ID.

    python3 scripts/install_linux_service.py add-harness myagent \
  --display MyAgent --instructions ~/.myagent/AGENTS.md \
  --mcp-config ~/.myagent/mcp.json
    Harnesses

  3. Send and watch

    Agents call send_message and replay_messages. From a terminal, follow the same context:

    comitia-client codex watch --context-id CONTEXT_ID \
  --agent-instance my-worker --for-instance my-worker
